# J22 M1 Employment Hub - September 2026 website update

Static Vercel-ready website for the Caddick J22 M1 Employment Hub at Cliffe Hill Farm, Markfield.

## Structure
- `index.html` - updated homepage and September 2026 current position
- `site.html` - site and planning policy position
- `proposals.html` - submitted scheme and headline benefits
- `current-position.html` - detailed response to points raised
- `faq.html` - determination-stage FAQs
- `styles.css` / `script.js` - shared presentation and interaction
- `assets/` - CGI and Caddick logo extracted from the September 2026 Member Update Briefing

## Deploy
This is a static site and needs no build command. Import the GitHub repository into Vercel and deploy with the framework preset set to **Other** if Vercel does not auto-detect static output.
